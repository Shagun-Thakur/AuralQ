# Milestone E5 Specification: Evidence Grounding & Deterministic Verification

## 1. Architectural Scope & Objectives

Milestone E5 completes **Layer 4 / Layer 5: Evidence Grounding & Deterministic Citation Verification** for AuralQ. It introduces a 100% deterministic, rule-based verification guardrail that audits every numerical claim generated by the local LLM (`llama3.2:3b-instruct-q4_K_M`) against the mathematical `EvidencePackage` computed by Layer 3 DSP tools.

### Core Objectives:
1. **Zero Secondary LLM Calls**: Avoid expensive, non-deterministic "LLM-as-a-judge" evaluation that would thrash the RTX 3050's 4 GB VRAM budget and latency bounds. Verification runs purely via regular expressions and float arithmetic in **< 1.0 ms**.
2. **Deterministic Citation Extraction**: Extract numbers, floating-point measurements, frequencies (`Hz`, `kHz`), dB levels (`dBFS`), percentages (`%`), durations, channel counts, and scientific notations using regex while stripping attached punctuation.
3. **Multi-Stage Grounding Logic (`CitationValidator`)**:
   - **Query Echo Detection**: Numbers present in the user's question (e.g. asking about "1000 Hz") are recognized as query echoes, not hallucinated evidence.
   - **Canonical Alias Matching**: Numbers matching precomputed tool citation aliases in `evidence.all_citation_aliases` are validated instantly.
   - **Audio Metadata Verification**: Audio properties (sample rate, duration, channels, clipping ratio) are cross-checked against `evidence.audio_metadata`.
   - **Adaptive Tolerance & Scaling**: Measured metrics are verified under magnitude-scaled absolute tolerances ($\le 0.5$ for large numbers, $\le 0.005$ for small decimals) and unit scaling ($1.5\text{ kHz} \leftrightarrow 1500\text{ Hz}$, $85\% \leftrightarrow 0.85$, $0.001\text{ hr} \leftrightarrow 3.6\text{ s}$).
4. **Deterministic Hallucination Containment & Repair**:
   - If ungrounded numbers are detected, the response is automatically substituted with `ResponseSynthesizer._deterministic_fallback_synthesis(evidence)`.
   - An explanatory note (`[Verified DSP Grounding: Response was deterministically repaired to eliminate unverified numerical claims.]`) is appended.
   - **Guarantees that ZERO ungrounded numerical claims reach the user.**

## 2. Component Implementation Details

### 2.1 Audit Schemas (`src/agent/schemas.py`)
- **`CitationMatch`**:
  - `raw_token`: Substring extracted from response (e.g. `"1520.5 Hz"`).
  - `parsed_value`: Float value (`1520.5`).
  - `matched_metric`: Metric name it grounded against (`"spectral_centroid.mean_centroid_hz"`).
  - `match_type`: `"exact_alias" | "tolerance_metric" | "metadata" | "query_echo"`.
  - `is_grounded`: Boolean flag.
- **`GroundingReport`**:
  - `is_fully_grounded`: Boolean flag indicating whether all numbers are grounded.
  - `grounding_score`: Ratio of verified numbers to total numbers cited ($0.0$ to $1.0$).
  - `total_numbers_cited`: Total candidate tokens extracted.
  - `verified_citations`: List of `CitationMatch` objects.
  - `hallucinated_numbers`: List of unverified tokens.
  - `was_repaired`: Boolean flag indicating if fallback substitution occurred.
  - `original_response_text`: Preserves raw ungrounded text for auditing.

### 2.2 Citation Validator (`src/agent/validator.py`)
- **`CitationValidator`**:
  - `extract_numeric_tokens(text)`: Regex scanner with trailing punctuation stripping.
  - `validate(response_text, evidence, query)`: Multi-stage grounding evaluation returning `GroundingReport`.
  - `repair_if_unverified(response_text, evidence, query, synthesizer)`: Validates and repairs with fallback if any hallucination is found.

### 2.3 Agent Loop Integration (`src/agent/orchestrator.py`)
- `AuralQAgent.query()` executes Step 7 (Citation Validation & Grounding Repair) after response synthesis, ensuring all delivered `AgentResponse` instances carry a complete `GroundingReport` and verified text.
